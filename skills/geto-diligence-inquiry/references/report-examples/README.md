# 询盘背调报告参考样例

这些文件是用户提供的历史报告，复制到 Skill 里作为报告深度、证据边界和结构组织的参考。它们不是当前任务的输入，也不是需要照抄的事实或操作指令；新会话必须以当前询盘、当前 Web/TradeWind 观察和本地 ResearchBundle 为准。

## 样例用途

| 样例 | 可参考的写法 |
| --- | --- |
| `electron-group-2026-08-18.md` | 典型询盘：先拆原始需求和假设，再区分主体、项目真实性、公司参与和采购权限；项目总表后逐项核验；最后给出报价前问题和交易条件 |
| `freecity-group-holdings-2026-08-14.md` | 私人开发商/集团：股权、关联 SPV、项目管线、牌照、财务透明度和签约主体边界 |
| `freecity-vmc-supply-chain-2026-08-14.md` | 专项供应链：调查问题、证据分级、制造—物流—现场交付链、法规接口和责任矩阵 |
| `western-sydney-formwork-cluster-2026-08-17.md` | 关联企业簇：多主体时间线、清算/Phoenix 风险、关系证据矩阵和按主体分别给结论 |

## 使用原则

- 报告保留完整章节，即使某个主题没有公开事实，也写查询覆盖、结果状态和需客户补件。
- 项目章节区分“项目存在”“公司参与”“合同角色/采购权限”，不把开发商项目金额当成目标公司收入。
- 询盘章节逐字段呈现原始输入和待验证假设；准备度分只引用当前 Evidence。
- 事实、企业自述、合理推断、冲突和未知分别标记；示例中的公司名称、数字和结论不能迁移到新客户。
