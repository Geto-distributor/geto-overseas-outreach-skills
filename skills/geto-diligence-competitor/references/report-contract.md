# 竞对深度报告合同

report.md 至少覆盖：执行摘要、主体与集团、产品/技术对标矩阵、商业控制与竞争类型、制造/工程/委外、目标市场、渠道/租赁/服务、项目与客户、关系网络、优势与限制、GETO 竞争与合作路径、证据冲突与缺口、查询覆盖、最终判断。

产品矩阵逐项列出 GETO competitionSurface、竞对产品/系统、重叠程度、替代性、商业角色、制造状态、目标市场和 Evidence。项目部分遵循“项目存在—竞对参与—合同角色或产品使用”三层证明。

项目与客户章节分别列出：具名对象、项目或产品、关系内容、当前或历史状态、证据状态、可支持结论、未闭合字段和下一步查询。公开资料较少时仍需提供查询覆盖表。

最终判断用 confirmed、possible 或 rejected 表达竞对分类，并说明适用的国家与产品面。公司规模、名称关键词、安装团队和单个项目保留其原始事实语义与证据边界。
