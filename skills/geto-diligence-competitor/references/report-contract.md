# 竞对深度报告合同

report.md 默认使用自然中文，至少覆盖：执行摘要、主体与集团、产品/技术对标矩阵、商业控制与竞争类型、制造/工程/委外、目标市场、渠道/租赁/服务、项目与客户、关系网络、优势与限制、GETO 竞争与合作路径、证据冲突与缺口、研究覆盖、事实底座、关键信号、AI 竞争推理、AI 结论、不确定性和继续研究方向。

产品矩阵逐项列出 GETO competitionSurface、竞对产品/系统、重叠程度、替代性、商业角色、制造状态、目标市场和 Evidence。项目部分遵循“项目存在—竞对参与—合同角色或产品使用”三层证明。

项目与客户章节分别列出：具名对象、项目或产品、关系内容、当前或历史状态、证据状态、可支持结论、未闭合字段和下一步查询。研究覆盖章节按官网栏目、社媒帖子、产品/系统、制造/工厂、项目/案例、外部交叉、Provider、采购链和分类分别列出覆盖状态、发现数、检查数、时间/分页边界、不可访问原因和下一步。公开资料较少时仍需提供这些覆盖信息。

最终判断用 confirmed、possible 或 rejected 表达竞对分类，并说明适用的国家与产品面。AI 还要解释竞对的商业控制、市场进入方式、客户/渠道结构、当前性、GETO 差异化和可能切入口；不能只罗列来源、状态或分数，也不能用“待人工判断”代替结论。公司规模、名称关键词、安装团队和单个项目保留其原始事实语义与证据边界。

法定名称、项目正式名、品牌和产品系统名可以保留原文；Evidence 原文不机械翻译。面向销售的摘要、项目判断、风险、行动和结论不得直接展示大段外语、snake_case 或原始对象。
